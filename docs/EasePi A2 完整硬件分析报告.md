# 二、【最关键】PCIe 通道分配

## 1. RK3568B2 原生 PCIe 控制器

- 硬件支持 **PCIe 3.0**

- 提供 **3 个 PCIe 接口**

- 分配如下：

    - **PCIe2x1**：用于 2.5G 以太网控制器
    - **PCIe3x1**：用于 M.2 NVMe 1
    - **PCIe3x2**：用于 M.2 NVMe 2

## 2. EasePi A2 实际硬件设计（根据设备树确认）

- 主板有 **3 个 PCIe 接口**：1 个用于以太网，2 个用于 NVMe

- 最终分配：

    - **M.2 NVMe 1：PCIe 3.0 x1**（pcie3x1）
    - **M.2 NVMe 2：PCIe 3.0 x1**（pcie3x2）
    - **2.5G 网口：PCIe 接口**（pcie2x1，RTL8125B）

## 3. 双 NVMe 工作模式

- 两个 NVMe **独立带宽、互不抢占**

- 单盘理论带宽：**~1000MB/s**（PCIe3.0 x1 8Gbps）

- 双盘合计理论带宽：**~2000MB/s**（PCIe3.0 x2 16Gbps）

- 实际单盘测速：**800–900MB/s** 正常

## 4. 2.5G 网口 RTL8125B 与 PCIe 关系

- RTL8125B 芯片通过 **PCIe 接口**连接（pcie2x1）

- **占用 RK3568 的原生 PCIe 通道**

- 因此：**双 NVMe 通道与网口共享 PCIe 资源**

---

# 三、M.2 接口详细定义

- 接口类型：**M‑Key**

- 协议：**仅 NVMe**

- 不支持：SATA 协议 M.2

- 支持尺寸：2280 / 2260 / 2242

- 供电：主板直接供电，一般无需额外供电

---

# 四、网络部分详细硬件

## 1. 有线 2.5G

- 芯片：**RTL8125B**

- 接口：RJ45

- 实际通路：PCIe2x1 → RTL8125B

- 性能：可跑满 **2.5Gbps**（300MB/s 左右）

## 2. 无线 Wi‑Fi / BT

- 模块：**AP6255**

- Wi‑Fi：802.11ac 双频

- 蓝牙：4.2

- 接口：**SDIO**

- 天线：外置单天线

---

# 五、USB 系统

- USB3.0 Type‑A：主接口，高速外设

- USB‑C：**仅 OTG / 调试**，不支持视频/充电

- USB 系统独立，**2.5G 网口通过 PCIe 连接，不共享 USB 总线**

---

# 六、电源与 PMIC

- PMIC：**RK809‑5**

- 多路同步降压 + LDO

- 为 CPU、DDR、eMMC、PCIe、USB、OLED 供电

- 整机功耗：

    - 待机：<5W

    - 双 NVMe + 满载：<20W

---

# 七、显示与交互

- OLED：128×64 I2C

- HDMI 2.0：4K@60fps

- 红外接收器

- 电源键、复位键、MaskROM 键

- 板载 LED：电源/运行

---

# 八、调试接口（开发必备）

- **TTL 串口（Debug UART）**：板载焊盘

- MaskROM 按键：短接可进入刷机模式

- 适合：U‑Boot 调试、内核启动日志、底层移植

---

# 九、【总结】EasePi A2 硬件真实定位

这是一台**为 NAS/软路由 深度优化的 RK3568 设备**，硬件设计非常清晰：

1. **CPU：RK3568B2 足够跑路由、NAS、Docker**

2. **PCIe：真正双 NVMe 独立通道（PCIe3.0 x1 + x1）**

    - 无交换芯片

    - 双盘性能均衡

    - 是同价位罕见的**双独立 NVMe 方案**

3. **网络：2.5G 够用，不抢 PCIe 通道**

4. **存储：双 NVMe + eMMC，纯高速结构**

5. **开发友好：TTL、MaskROM、开源度高**

---

# 十、结论

**EasePi A2 使用 RK3568B2 原生 PCIe 3.0 控制器，提供 3 个 PCIe 接口：2 个用于双 M.2 NVMe（各 PCIe 3.0 x1），1 个用于 2.5G 以太网控制器（RTL8125B）。无 PCIe Switch，所有设备直接连接到 RK3568 的 PCIe 控制器。整机为高性能双 NVMe NAS/软路由 设计。**
